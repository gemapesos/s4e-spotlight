# Product

## Register

product

## Platform

web

## Users

Chrome users who want a fast, keyboard-first command surface available while browsing ordinary webpages.

## Product Purpose

Provide one dependable shortcut for Seller Central operational tools: turn messy Case ID or Shipment ID text into tabs, open Time Out resources, and switch stores using locally encrypted account data.

## Positioning

A focused Manifest V3 command palette for fast, keyboard-first Seller Central support workflows.

## Brand Personality

Quiet, familiar, precise.

## Anti-references

Avoid decorative extension chrome, custom visual branding, noisy animation, persistent tracking, and actions that are not explicitly initiated by the user.

## Design Principles

- Match the supplied component reference before adding interpretation.
- Keep keyboard behavior predictable and reversible.
- Tolerate messy operational input while producing deterministic actions.
- Keep newly opened work in the background so the user retains their current context.
- Isolate the interface from host-page styles and scripts.
- Request only the access required for the shortcut to work.
- Keep account secrets encrypted at rest, local to the Chrome profile, and unavailable to ordinary page content.

## Accessibility & Inclusion

Preserve focus, support complete keyboard navigation, expose dialog and listbox semantics, maintain readable contrast in both system themes, and reduce motion when requested by the operating system.
